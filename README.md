## 🌟 Overview
A clean, premium, and professional personal portfolio website designed with a **modern minimalist** dark navy blue and crisp white aesthetic. Developed with pure semantic **HTML5**, modular **CSS3**, and vanilla **JavaScript** with zero heavy framework bloat.

The portfolio is mobile-first, 100% responsive across devices (mobile, tablet, desktop), accessible (WCAG AA contrast compliant), and built with smooth animations, interactive scrollspy navigation, and functional forms.

## 💻 How to Run the Website

### Option 1: Direct File Open
Simply double-click `index.html` to open it in any web browser (Chrome, Edge, Firefox, Brave, Safari).

### Option 2: Using VS Code Live Server
1. Open the `code soft` folder in Visual Studio Code.
2. Right-click `index.html` and click **"Open with Live Server"**.
3. The portfolio will automatically open at `http://127.0.0.1:5500`.

## 🛠️ Personalization Guide
- **Update Social Links:** Open `index.html` and update the `href` attribute in the LinkedIn and GitHub anchors under the `#contact` section.
- **Upload Real Resume:** Replace `assets/docs/Vijayaragavan_V_Resume.pdf` with your updated college resume PDF using the exact same file name.
- **Update Profile Photo:** If you prefer a real photograph over the modern SVG portrait, place your photo (e.g. `avatar.jpg`) inside `assets/images/` and change `src="assets/images/avatar.svg"` to `src="assets/images/avatar.jpg"` in `index.html`.
